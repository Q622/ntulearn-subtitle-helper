# NTULearn 字幕助手（Microsoft Edge 扩展）

为 NTULearn 课程回放视频导入本地 SRT 字幕，支持字号调节、播放倍速和字幕时间偏移。无需安装依赖或构建，使用 Manifest V3。

## 安装

1. 如使用 ZIP，先解压到一个固定目录。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开「开发人员模式」，点击「加载解压缩的扩展」。
4. 选择包含 `manifest.json` 的目录（不要选择它的上一级目录）。
5. 在 Edge 工具栏的扩展菜单中固定「NTULearn 字幕助手」。

## 使用

1. 打开 NTULearn 的课程回放，先开始播放，让页面完成播放器加载。
2. 点击工具栏中的扩展图标。没有找到视频时，点击「重新检测」。
3. 多画面回放时，从「目标视频」选择字幕要显示的画面。默认优先选择播放中的大画面。
4. 点击「选择本地 SRT 字幕」，选择对应课程的 `.srt` 文件，字幕立即生效。
5. 用滑块调节字号（12–72 px），通过下拉框调节视频速度（0.25–4×）。
6. 如果字幕出现太早，将「字幕时间偏移」设为正数，例如 `2` 表示晚 2 秒；太晚则用负数。

关闭扩展弹窗后字幕继续显示。再次打开可修改已加载字幕。字号偏好保存在本机；字幕文件和字幕内容仅保留在当前页面内存中，刷新页面、切换课程或播放器重建后需要重新导入。时间偏移和倍速不跨课程保存。

编码默认识别带 BOM 的 UTF-16 LE/BE，其他文件按 UTF-8 读取。中文出现解码错误时可切换「GB18030 / GBK」，已选择的文件会重新读取。单个文件上限 5 MB。支持多行字幕、重叠时间段、逗号或点号毫秒格式；无效段落会跳过并显示数量。不执行字幕中的 HTML，常见格式标签会去除。

## 同步与播放器兼容性

- 通过 HTMLVideoElement 的原生 TextTrack / VTTCue 显示字幕，时间轴由浏览器按视频时间处理。暂停、跳转、倍速无需单独计算字幕时钟；采用 `[开始, 结束)` 时间语义。
- 原生字幕轨道支持普通页面和视频全屏。系统画中画能否显示字幕取决于 Edge / Windows 的实现，未作保证。
- 扫描各个获得权限的 iframe 和开放 Shadow DOM 内的视频。自动站点权限覆盖 `*.ntu.edu.sg`、`*.kaltura.com`、`*.kaltura.net`、`*.panopto.com`、`*.panopto.eu` 的 HTTPS 页面。点击扩展时也可操作其他普通页面的主框架视频，但不自动获得其他域名的跨域 iframe 权限。
- 调速会应用到所选视频所在 iframe 内的视频与音频，避免常见双画面播放器同框架音画速度不一致。分处不同 iframe 的独立媒体需要分别设置速度。
- 页面播放器自己再次改变速度时，以播放器的设置为准；点击「重新检测」可查看当前值。网站强制锁速或使用非 HTML5 视频时可能无法兼容。
- 导入本地字幕时暂时关闭所选视频上已开启的原生字幕，点击「清除字幕」恢复。播放器自行绘制的字幕需要在播放器菜单中手动关闭。
- 换课后请重新检测并导入对应课程字幕，避免课程与字幕不匹配。封闭 Shadow DOM、受限 iframe、浏览器内置页面和特殊受保护播放器不在支持范围内。

## 排查

- **找不到视频**：开始播放后重新检测；确认扩展在该站点有访问权限；尝试通过课程页面的播放器入口在新标签页打开回放。若实际播放器使用上述列表之外的域名，需要将准确域名补充到 `manifest.json` 的 `host_permissions` 和 `content_scripts.matches`，在扩展页重新加载扩展，并刷新课程页面。
- **字幕未出现**：确认当前视频时间处于 SRT 的时间范围、已勾选「显示字幕」，并检查目标视频是否选对。`examples/demo.srt` 可验证视频开头 15 秒的字幕。
- **刷新扩展后无响应**：刷新课程页面，重新检测并导入字幕。

## 隐私与权限

扩展不发送网络请求，不上传 SRT，不收集账号、课程或播放记录，不需要服务端。`activeTab` 用于用户点击后的当前页面访问，`scripting` 用于检测和控制播放器，`storage` 仅保存字号；站点权限用于访问课程视频所在的跨域嵌入框架。代码不含远程脚本。

## 开发验证

有 Node.js 时运行：

```powershell
node tests/run.cjs
```

测试覆盖 SRT 解析、无效段落、重叠字幕、时间偏移、原生轨道生命周期、字号、调速、多媒体同步、替换视频、重复注入与清除后恢复字幕。测试使用模拟媒体元素；未登录 NTULearn 实际课程进行端到端验证。

安装后建议用 `examples/demo.srt` 检查：1×/2× 播放、暂停、拖动到第 7 秒、全屏和字号调节。拖到第 7 秒应显示第 2 条字幕，无论播放速度是多少。
